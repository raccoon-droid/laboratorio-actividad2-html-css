HTML (HyperText Markup Language)


Es el lenguaje estándar para estructurar el contenido de las páginas web.
No es un lenguaje de programación propiamente dicho, sino un lenguaje de marcado.

CSS (Cascading Style Sheets)


Es un lenguaje de diseño que define la apariencia visual de los documentos escritos en HTML.
